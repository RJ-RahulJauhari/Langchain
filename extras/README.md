# Extras — Miscellaneous Files

This folder contains small utility files that don't belong to a specific learning topic.

| File | What it is |
|------|-----------|
| `test.ipynb` | A one-cell notebook that prints the installed LangChain version — useful to quickly verify your environment is set up correctly |

## How to use test.ipynb

```bash
source .venv/bin/activate
jupyter notebook extras/test.ipynb
```

Run the single cell. If it prints a version number without errors, your environment is working.
